# Crud sem internet com express

## Ideia Principal

- Crie uma CRUD simples de cadastrar produtos em express com ts
  - [x] create product
  - [x] read product
  - [x] update product
  - [ ] delete product

## Features Implementadas

### Create Product (POST /api/products)
- Endpoint para criar novos produtos
- Recebe `name` e `price` no body
- Retorna o produto criado com ID

### Read Products (GET /api/products)
- Lista todos os produtos ordenados por ID
- Retorna array de produtos

### Read Product by ID (GET /api/products/:id)
- Busca produto específico por ID
- Retorna 404 se não encontrado

### Update Product (PATCH /api/products/:id)
- Atualiza produto existente
- Recebe `name` e `price` no body
- Retorna 404 se produto não existe
